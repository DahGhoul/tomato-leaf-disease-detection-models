## 🧪 Pruebas Estadísticas Implementadas

### 1. **Pruebas de Concordancia Modernas**

#### 📌 Coeficiente Kappa de Cohen
```python
kappa_scores[f"{model1} vs {model2}"] = 1.0 if pred1 == pred2 else 0.0
```
- **¿Qué mide?** El nivel de acuerdo entre dos clasificadores
- **Interpretación:**
  - κ = 1: Acuerdo perfecto
  - κ = 0: Acuerdo equivalente al azar
  - κ < 0: Peor que el azar
- **Uso en el sistema:** Compara predicciones entre pares de modelos

#### 📌 Análisis de Entropía
```python
entropy = -np.sum(probs * np.log2(probs + 1e-10))
```
- **¿Qué mide?** La incertidumbre en las predicciones
- **Interpretación:**
  - H < 1: Baja incertidumbre (modelo seguro)
  - 1 ≤ H ≤ 2: Incertidumbre moderada
  - H > 2: Alta incertidumbre (revisar)
- **Beneficio:** Identifica cuando un modelo no está seguro

#### 📌 Análisis de Consenso Ponderado
```python
consensus_probs = {disease: np.mean(probs) for disease, probs in all_predictions.items()}
```
- **¿Qué hace?** Combina predicciones de todos los modelos
- **Método:** Promedia probabilidades por clase
- **Ventaja:** Reduce sesgo individual, mejora robustez

### 2. **Pruebas Estadísticas Tradicionales**

#### 📌 T-Test Pareado
```python
t_stat, p_value = stats.ttest_rel(acc1, acc2)
```
- **¿Qué evalúa?** Si hay diferencia significativa entre precisiones
- **Datos usados:** Histórico simulado basado en precisiones reportadas
- **Interpretación:**
  - p < 0.05: Diferencia estadísticamente significativa
  - p ≥ 0.05: Sin diferencia significativa
- **Ejemplo:** MobileNetV3 (95.2%) vs EfficientNetB7 (97.8%)

#### 📌 Prueba Z de Proporciones
```python
z = (p1 - p2) / se
p_value = 2 * (1 - stats.norm.cdf(abs(z)))
```
- **¿Qué compara?** Tasas de acierto entre modelos
- **Simulación:** 1000 imágenes de validación
- **Interpretación:**
  - |z| > 1.96: Diferencia significativa (α = 0.05)
  - p < 0.05: Proporciones diferentes

## 🔍 Interpretación de Resultados

### Escenarios de Decisión

#### ✅ Escenario 1: Alta Confianza y Consenso
```
- Todos los modelos coinciden
- Entropía < 1 en todos
- Confianza > 90%
→ Acción: Proceder con tratamiento recomendado
```

#### ⚠️ Escenario 2: Desacuerdo entre Modelos
```
- Modelos difieren en predicción
- Entropía variable
- Kappa < 1
→ Acción: Usar consenso ponderado + consultar experto
```

#### ❓ Escenario 3: Baja Confianza General
```
- Confianza < 70% en todos
- Entropía > 2
- Alta incertidumbre
→ Acción: Tomar nueva imagen, verificar calidad
```

## 💻 Código de Ejemplo para Interpretación

```python
# Evaluar calidad de predicción
def evaluate_prediction_quality(predictions, statistical_results):
    # Verificar consenso
    models_agree = len(set([p['prediction'] for p in predictions.values()])) == 1
    
    # Verificar confianza promedio
    avg_confidence = np.mean([p['confidence'] for p in predictions.values()])
    
    # Verificar entropía promedio
    entropies = []
    for p in predictions.values():
        entropy = -np.sum(p['probabilities'] * np.log2(p['probabilities'] + 1e-10))
        entropies.append(entropy)
    avg_entropy = np.mean(entropies)
    
    # Clasificar calidad
    if models_agree and avg_confidence > 0.9 and avg_entropy < 1:
        return "EXCELENTE - Proceder con confianza"
    elif avg_confidence > 0.7 and avg_entropy < 1.5:
        return "BUENA - Resultado confiable"
    elif avg_confidence > 0.5:
        return "MODERADA - Considerar verificación"
    else:
        return "BAJA - Requiere revisión manual"
```
